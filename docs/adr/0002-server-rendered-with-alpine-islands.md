# Серверный рендеринг с Alpine-островами вместо SPA

Страницы рендерит Django, интерактив закрывают острова Alpine.js, а JSON-эндпоинты REST-слоя обслуживают только конкретные действия (поиск продукта, добавление и правка записи). Альтернатива — SPA-фронт, ходящий в API за всем, — отвергнута: для семейного трекера на 2–3 человек она приносит полную стоимость SPA (сборка, клиентское состояние, дублирование валидации) без соответствующей выгоды.

## Considered Options

- **SPA-фронт поверх REST** — отвергнут: масштаб продукта не оправдывает.
- **Server-rendered + Alpine-острова** — выбран: Django остаётся источником правды, REST и Alpine работают точечно.

> JSON-слой отменён, роли htmx и Alpine уточнены — см. ADR-0003.
